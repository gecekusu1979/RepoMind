# RepoMind Chrome Extension

This is the official Manifest V3 extension for launching RepoMind directly from GitHub.com. 

## Loading the Extension Locally

1. Open Chrome / Edge and go to `chrome://extensions/`
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked**.
4. Select this `extension` folder (`C:\Users\ayhan\OneDrive\Desktop\repomind\extension`).
5. Navigate to any public GitHub repository (e.g., https://github.com/vercel/next.js).
6. Look for the purple **🧠 Analyze in RepoMind** button at the top right, next to the Star/Fork buttons.
7. Click the button to instantly open a new tab in your local RepoMind instance (`http://localhost:3000`).

Wait for the RepoMind tab to load, enter WebLLM mode for in-depth AI answers, check Bus Factors, Architecture flowcharts, and more.
